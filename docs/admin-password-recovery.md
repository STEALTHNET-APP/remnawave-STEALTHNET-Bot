# Сброс пароля администратора

На сервере откройте папку проекта и выполните:

```sh
make reset-admin-password
```

Или напрямую через Docker Compose:

```sh
docker compose exec api node dist/scripts/reset-admin-password.js
```

Введите email существующего администратора, новый пароль и его подтверждение.
Пароль при вводе не отображается и не передаётся в аргументах команды.
Требования: минимум 8 символов, максимум 72 байта UTF-8 (ограничение bcrypt).
Для отмены нажмите Ctrl+C.

Команда меняет пароль только выбранного аккаунта с ролью ADMIN. Новые аккаунты
не создаются, роли и двухфакторная аутентификация не меняются. Если включена 2FA,
для входа по-прежнему нужен код из приложения-аутентификатора.

Сохранённые refresh-токены этого администратора удаляются. Ранее выданные
access-токены остаются действительными до своего истечения. Не используйте
эту команду как способ немедленно отключить все сессии скомпрометированного аккаунта.
Изменение записывается в аудит-лог как `admin.password_recovery`, без пароля.

Для запуска без Docker сначала соберите backend, затем выполните в его папке:

```sh
npm run admin:reset-password
```

Параметры подключения к базе берутся из окружения или `.env`.
Изменение `INIT_ADMIN_PASSWORD` не меняет пароль уже существующего администратора.
