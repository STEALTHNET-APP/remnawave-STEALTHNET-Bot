# Настройки API

В админке откройте **Настройки → API**. Здесь можно проверить и сохранить адрес Remnawave, API-токен и cookie reverse proxy. Изменения применяются в API сразу после сохранения; другие процессы перечитывают настройки в течение 30 секунд. Пустой cookie отключает его. «Сбросить к .env» возвращает настройки окружения.

Смена адреса API не переносит пользователей между серверами Remnawave. Перед переездом сделайте резервную копию и перенесите базу самой Remnawave с сохранением UUID. Локальные привязки подписок не сбрасываются.

## Токен Telegram

Проверьте новый токен кнопкой «Проверить токен». После его сохранения панель использует новый токен для авторизации и уведомлений. Старый токен больше не принимается.

Для бота, Stars и уведомлений также замените `BOT_TOKEN` в серверном `.env`, затем пересоздайте контейнер:

```sh
docker compose up -d --force-recreate api bot broadcast-worker
```

Обычный `docker compose restart bot` не перечитывает окружение контейнера. До пересоздания бот продолжает работать со старым токеном и не сможет авторизоваться в API. Планируйте замену вместе с пересозданием контейнера. Для смены самого бота пользователям потребуется открыть нового бота и нажать `/start`.
