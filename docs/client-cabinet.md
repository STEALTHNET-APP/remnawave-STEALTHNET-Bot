# Обновлённый личный кабинет

Кабинет открывается по адресу `https://ВАШ-ДОМЕН/cabinet/`. Новый интерфейс заменяет Classic и работает с существующим API STEALTHNET. Переносить клиентов, баланс и подписки в другую базу или устанавливать второй бэкенд не нужно.

## Обновление

1. Создайте и скачайте свежий бэкап в разделе **Бэкапы**.
2. Обновите установку по [инструкции обновления](auto-update.md). Если изменения доступны только в `main`, выберите источник **Получать последние обновления**. Ветка Release и LTS обновляются отдельно.
3. Дождитесь завершения обновления и перезагрузите страницу кабинета. Не обновляйте вкладку во время незавершённой оплаты.
4. Проверьте вход, свои подписки, баланс и историю. Названия подписок можно менять в их настройках.

Обновляйте API и фронтенд вместе. В поставку входит миграция `20261028160000_subscription_custom_name`: она добавляет поле названия подписки, не удаляя существующие записи. Стандартный контейнер API применяет миграции при запуске. Для установки без стандартного entrypoint сначала выполните обычную процедуру миграций проекта, затем запустите новую сборку.

Если после обновления данные не загружаются, проверьте результат обновления и журнал API по основной инструкции. Не создавайте новую базу и не удаляйте старую установку.

## Вход и регистрация через Telegram

Если ваш бот уже работал с этой установкой, используется тот же бот. Для владельца сервиса:

1. В админке откройте настройки API Telegram и проверьте **Юзернейм бота (без @)**. Это имя после `t.me/`, а не отображаемое название бота. Сохраните настройки.
2. Убедитесь, что сервис бота запущен. У API и бота должен быть один и тот же `BOT_TOKEN` в конфигурации установки. Не вставляйте этот токен во фронтенд и не публикуйте его.
3. Откройте кабинет в приватном окне браузера. На входе должна появиться кнопка **Войти через Telegram**, на регистрации — **Зарегистрироваться через Telegram**. Если кнопки нет, проверьте юзернейм и загрузку настроек сервиса.
4. Нажмите кнопку. В открывшемся Telegram нажмите **Запустить** в боте. После подтверждения вернитесь в браузер: кабинет откроется автоматически.

Если Telegram не открылся, нажмите **Открыть Telegram** под кнопкой ожидания. Можно отменить ожидание и начать заново. Ссылка действует пять минут; после истечения получите новую кнопкой входа.

Существующий Telegram-аккаунт входит в свой профиль с прежним балансом и подписками. Новый аккаунт проходит первоначальную настройку. Если включена двухфакторная защита, после подтверждения в боте потребуется код. Для входа через этот сценарий используется ссылка на бота; настройка домена Telegram Login Widget не требуется.

## Оформление

Внешний вид назначает администратор. Режим **Светлая / Тёмная / Системная** и цветовой акцент применяются к клиентскому кабинету. Системный режим учитывает оформление устройства пользователя. Пользователь не переключает тему самостоятельно.

Aurora и Stealth остаются отдельными вариантами оформления с прежними настройками применения в Telegram и браузере. Визуальный конструктор страниц в это обновление не входит.

## Проверка перед публикацией в main

Проверены сборки API и фронтенда; автоматические проверки конфигурации, оформления, навигации и PWA. На изолированной базе проверены настоящие HTTP-маршруты Telegram: вход, создание аккаунта, блокировка, 2FA, истечение и повторное использование токена, конкурентные запросы. Также проверены права на переименование подписок.

В браузере проверены мобильные формы входа и регистрации, ожидание, повторная ссылка, отмена и переход в первоначальную настройку после тестового подтверждения. Подтверждение для браузерной проверки моделировалось в изолированной базе. Вход через настоящий Telegram-бот и физический Telegram WebView в этой проверке не выполнялся; владельцу следует пройти шаги выше на своей установке. Реальные списания и выдача VPN не выполнялись.
