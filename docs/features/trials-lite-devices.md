# Платные триалы, Lite и лимит устройств

## Триалы (#42)

В разделе «Триалы» можно задать цену в рублях. Ноль оставляет триал бесплатным. Платный триал оплачивается с внутреннего баланса; пополнение работает через уже настроенные платёжные системы. Перед списанием клиент подтверждает цену. Один и тот же триал можно активировать один раз.

Для обновления нужна миграция `20261019090000_paid_trials`. Старые триалы получают цену 0. Автопродление у выданного триала выключено.

При явном отказе выдачи деньги возвращаются на баланс. При неопределённом результате внешнего API платёж остаётся PROCESSING, а повторная выдача блокируется. Администратору нужно сверить подписку с Remnawave перед возвратом или завершением выдачи; автоматический возврат в такой ситуации мог бы выдать подписку бесплатно.

## Lite (#150)

«Настройки → Общие → Lite-режим кабинета и бота». Работает в общей версии. После переключения откройте кабинет заново, в боте отправьте `/start`.

Кабинет показывает подписки, покупку, продление, подключение, пополнение и поддержку. Главное меню бота также сокращено. Админка и данные сохраняются; выключение возвращает полный интерфейс. Это настройка интерфейса, а не запрет доступа к API остальных функций.

## Дополнительные устройства (#43)

Ограничение берётся из `maxExtraDevices` конкретного тарифа. Ноль запрещает докупку. Уже купленные дополнительные устройства учитываются при следующей покупке пакета и при покупке устройств вместе с продлением.

Неоплаченные счета не занимают лимит. Перед выдачей оплаченного пакета лимит проверяется повторно. Если он исчерпан или подписка уже недоступна, оплаченная сумма один раз зачисляется на внутренний баланс. В уведомлении указано зачисление вместо выдачи устройств.

## Проверки

Из папки backend:

- `npm run build`
- `node tests/trial-activation-guard.cjs`
- `node tests/device-limit.cjs`
- `node --experimental-vm-modules tests/features-42-43-postgres.mjs` — только на тестовой PostgreSQL с применёнными миграциями. Создаёт временные записи, очищает их в finally; Remnawave заменён тестовым ответом, реальные платежи не выполняются.

Из папки bot: `npm run build`, затем `node tests/lite-menu.mjs`. Из frontend: `npm run build`.
