## Где что настраивается

- **`.env` на сервере** — домен, подключение к БД, секреты авторизации и исходные параметры сервисов. Корневой `.env` создаёт [установщик](../../install.sh); его переменные используются в [Compose](../../docker-compose.yml). Для локальной разработки есть отдельные примеры [API](../../backend/.env.example) и [бота](../../bot/.env.example); они не заменяют конфигурацию Docker-установки.
- **Админка → Настройки** — оформление, Telegram-бот, платёжные системы и остальные параметры, доступные через интерфейс.
- **Docker Compose** — состав сервисов, подключения и хранилища. Исходная схема: [`docker-compose.yml`](../../docker-compose.yml). Установка может использовать дополнительные override-файлы.

Не публикуйте `.env`, токены бота, ключи платёжных систем и пароли. Начальные `INIT_ADMIN_EMAIL` и `INIT_ADMIN_PASSWORD` предназначены для создания администратора; для восстановления существующего аккаунта есть [отдельная инструкция](../admin-password-recovery.md).

Смена `POSTGRES_PASSWORD` в `.env` сама по себе не меняет пароль в уже созданной БД. При ошибке P1000 смотрите [диагностику](../operations/troubleshooting.md).

## Встроенный nginx

Этот режим выбирается в установщике. Nginx и certbot используют профиль `builtin-nginx`. Домен должен указывать на сервер; порты 80 и 443 должны быть доступны для выбранного способа выпуска сертификата.

- [Проверка и продление SSL](../SSL-RENEWAL.md).
- [Cloudflare DNS и wildcard-сертификаты](../CLOUDFLARE_SSL.md).

## Внешний reverse proxy

Если в установщике выбран внешний nginx, HTTPS и конфигурация прокси настраиваются отдельно. Отправная точка — [`nginx/external.conf.example`](../../nginx/external.conf.example). Замените домен и пути сертификатов своими, затем проверьте конфигурацию nginx перед перезагрузкой.

API доступен на порту 5000, статические файлы при штатной внешней установке копируются в `/var/www/stealthnet/`. Проверьте фактические подключения в Compose: базовый файл публикует API-порт на хосте; для nginx на том же сервере ограничьте доступ к API локальным интерфейсом в конфигурации своей установки.

Не копируйте готовый конфиг поверх рабочего без проверки домена, сертификатов и маршрутов других сайтов.

## Обновление конфигурации

Для обновления панели используйте [инструкцию обновлятора](../auto-update.md). Обычный `docker compose restart` перезапускает контейнеры, но не пересоздаёт их с изменёнными параметрами и не устанавливает новый образ.
