# Два аккаунта у одного клиента

[← Обслуживание](README.md)

В старых версиях вход через сайт и `/start` могли создать разные аккаунты. Два профиля с одинаковым Telegram ID в Remnawave также могут быть отдельными оплаченными подписками. Само совпадение ID не означает, что один из них можно удалить.

## Сохранить действующую подписку

Не удаляйте пользователя из Remnawave для исправления дубля: ссылка, которую клиент уже добавил в приложение, перестанет работать.

1. Найдите аккаунты клиента в панели. Сверьте Telegram ID, email, историю платежей и ссылки подписок. Сделайте резервную копию базы панели перед ручными действиями.
2. Если один аккаунт зарегистрирован на сайте, а второй создан только в боте, попросите клиента войти в исходный кабинет и привязать свой Telegram через настройки профиля.
3. После подтверждения владения Telegram панель объединит аккаунты. Подписки, баланс и платежи перейдут в исходный кабинет. Профили Remnawave и их ссылки сохранятся, включая старые подписки без отдельной записи в таблице подписок.
4. Проверьте подписки в кабинете и вызовите `/start` в боте. Если у клиента несколько настоящих подписок, они должны остаться отдельными.

Если у обоих аккаунтов есть собственные email, пароль или вход через соцсети, автоматическое объединение не выполняется. Администратору нужно сначала установить, какие аккаунты действительно принадлежат одному человеку. Не меняйте Telegram ID и UUID наугад и не удаляйте историю платежей.

## Что делает `/start`

Текущая версия ищет существующие профили по подтверждённому Telegram ID и восстанавливает недостающие привязки. Уже привязанный к другому аккаунту профиль не забирается автоматически. При недоступности Remnawave ошибка поиска не считается отсутствием подписки.

Исправление объединения предотвращает новые удаления. Если профиль Remnawave уже удалён вручную или старой версией, восстановить его прежнюю ссылку только из базы панели может быть невозможно: нужна резервная копия Remnawave.
