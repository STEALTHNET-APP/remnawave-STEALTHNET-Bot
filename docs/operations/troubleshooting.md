# Решение проблем

[← Обслуживание](README.md)

## Обновление не устанавливается

Откройте **Настройки → Обновления**, сохраните точный текст ошибки, текущую версию и коммит. Следуйте [инструкции по своей ситуации](../auto-update.md): для старого обновлятора предусмотрено восстановление через SSH.

Сообщения `[remna-sync]` относятся к синхронизации с Remnawave и сами по себе не объясняют отказ обновления. Не удаляйте Docker-тома и не переустанавливайте панель для устранения блокировки обновлятора.

## API не запускается: P1000 / Authentication failed

Это ошибка авторизации в базе, а не признак нехватки места. Частая причина — `.env` содержит новые реквизиты, а сохранённая БД была создана со старыми.

1. На сервере в каталоге панели посмотрите последние ошибки:

   ```bash
   docker compose logs --tail=100 api postgres
   ```

2. Сверьте параметры БД в `.env` с реквизитами действующей установки или её резервной копии. Не отправляйте файл и пароли в публичные обсуждения.
3. Если пароль БД утрачен, требуется отдельное восстановление доступа с сохранением данных. Не выбирайте очистку в установщике: удаление БД не восстанавливает доступ к прежним клиентам.

## В боте старое меню или нет виджета

- После сохранения меню подождите до минуты и отправьте `/start`: уже отправленные сообщения остаются прежними.
- Проверьте личный выбор обычного меню у клиента.
- Прочитайте [ограничения HTML-виджетов](../bot/widgets.md). Рабочий HTML-предпросмотр не означает, что Telegram разрешает отправку.

## Как собрать информацию для поддержки

В разделе **Диагностика** можно скачать отчёт поддержки. Перед скачиванием интерфейс показывает его состав. Архив JSON.gz содержит версию, результаты проверок, состояние обновления и обезличенную сводку событий. Исходные журналы, настройки, пароли, токены и клиентские данные не включаются; файл никуда автоматически не отправляется.

В обращении укажите версию и коммит, время ошибки, выполненное действие и точный текст сообщения. Прикладывая свои скриншоты и логи, отдельно уберите секреты и данные клиентов: обезличивание архива не распространяется на файлы, которые вы добавляете самостоятельно.
