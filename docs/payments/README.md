# Платёжные системы

[← Документация](../README.md)

Откройте **Настройки → Платёжные системы**. Каждый провайдер настраивается в своей карточке: реквизиты, включение и адрес уведомлений об оплате. Используйте адрес, который показывает ваша панель, с вашим доменом.

| Руководство | Содержание |
| --- | --- |
| [CloudPayments](../cloudpayments.md) | Подключение, рекуррентные платежи, чеки, прямая оплата в боте, отмена и возвраты |
| [RivaraPay](rivarapay.md) | Подключение, тестовый режим, уведомления, возвраты и промокод STEALTHNET |
| [Telegram Stars](../telegram-stars.md) | Настройка оплаты звёздами |

Для CisPay, RollyPay и других провайдеров параметры и пояснения находятся непосредственно в их карточках в админке. Отдельные пошаговые руководства по ним пока не написаны. Наличие интеграции не означает, что для неё уже есть полная инструкция в документации.

## Проверка подключения

1. Заполните карточку провайдера и сохраните настройки.
2. Настройте уведомления у провайдера по адресу из панели, если они требуются этой интеграции.
3. Пройдите предусмотренный провайдером тестовый сценарий. Проверьте не только открытие формы, но и получение уведомления и результат в истории платежей.
4. Для автоплатежей и чеков используйте отдельные настройки соответствующего провайдера. Эти возможности различаются между интеграциями.
