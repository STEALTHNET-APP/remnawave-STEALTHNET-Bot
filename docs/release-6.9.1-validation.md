# Проверки 6.9.1

Проверен объединённый код PR #257–#261 с исправлениями в коммите `d446ef4`. После этого изменены только номера версий, changelog и описание релиза.

- Сборки backend, bot и frontend прошли. Проверены TypeScript, Vite и сборка PWA.
- 26 проверок webhook, публичной конфигурации, часовых поясов рулетки, хранения тикетов и отката создания VPN-профиля прошли.
- 15 сценариев покупки и замены триала прошли. Отдельно пройдены проверки повторной активации, неизвестного результата запроса и миграции темы письма.
- Пройден набор проверок конкурентных платёжных уведомлений, пополнений, возвратов, конструктора тарифа и повторных списаний Lava.top.
- Добавлены проверки отсутствующего идентификатора уведомления Lava.top, сохранения такого уведомления для разбора и ошибки записи журнала. Проверены повторы с постоянным идентификатором и новые периоды списания.
- 10 проверок способов оплаты, данных подписки и навигации профиля Aurora прошли.
- Шесть сценариев тикетов выполнены через API и отдельную PostgreSQL 16: массовое закрытие, ответ без открытия закрытых обращений, JSON-флаг автозакрытия, повторное открытие клиентом, удаление закрытых и настройки хранения.
- В Chromium проверены настройки webhook на ширинах 320, 390 и 1440 px, настройки рулетки на 390 и 1440 px. Проверены подтверждения, сохранение черновика, обработка ошибок и отсутствие горизонтального переполнения.
- Отдельный браузерный тест подтвердил закрытие окна после успешной оплаты балансом и единственный вызов оформления покупки.
- Версия 6.9.1 совпадает в `version.json`, трёх `package.json` и трёх lock-файлах. Зависимости в манифестах совпадают с корневыми записями lock-файлов.
- Относительно тега `v6.9.0` схема Prisma и миграции не изменены.

Тестовая БД была создана отдельно от рабочей на стенде и удалена после прогона. Локальный тестовый API остановлен. Платёжные провайдеры и Remnawave в регрессионных тестах заменены заглушками; реальные списания и выдача доступа на рабочем сервере не выполнялись. CI в GitHub для этих изменений не настроен.
