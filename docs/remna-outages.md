# Если Remnawave недоступна

После трёх сетевых ошибок или отказов сервера панель на 30 секунд прекращает обращения к Remnawave. Затем один запрос проверяет восстановление связи. После успешной проверки действия снова доступны. Смена настроек подключения сбрасывает состояние этой защиты.

Покупка тарифов Remnawave, выдача триала и изменение устройств могут временно возвращать сообщение о недоступности. Пополнение баланса, Sing-box и прокси не блокируются этой проверкой. В списке тарифов можно нажать «Проверить снова».

Список подписок при сетевом сбое показывает последние сохранённые сроки и счётчики с признаком `isOfflineSnapshot`. Эти данные могут устареть. Новая ссылка подписки из адреса API не строится. Недоступность API сама по себе не подтверждает ни работу, ни остановку VPN-соединений.

## Уже оплаченные покупки

Обработка уведомлений платёжных систем сохранена. Новая автоматическая очередь повторных активаций не включена: потерянный ответ Remnawave не доказывает, что операция не выполнилась.

Если деньги получены, а активация завершилась ошибкой, проверьте платёж, соответствующую подписку и состояние пользователя в Remnawave. Повторять активацию из админки следует только после проверки, что услуга ещё не была выдана. Это предотвращает повторное продление или создание второго профиля.
