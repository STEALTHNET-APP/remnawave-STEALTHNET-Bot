# STEALTHNET

Панель управления VPN-подписками: Telegram-бот, клиентский кабинет, Mini App и админка. Интеграция с Remnawave, установка через Docker.

## Возможности

- Тарифы, триалы, покупка и продление подписок, лимиты устройств.
- Платёжные интеграции, внутренний баланс; чеки и автоплатежи для поддерживающих их провайдеров.
- Настраиваемое меню Telegram, компактный вид и предпросмотр. Для HTML-виджетов действуют [ограничения Telegram](../bot/widgets.md).
- Оформление кабинета и Mini App, управление клиентами, рефералы и промокоды.
- Аналитика, обращения в поддержку, бэкапы, обновления и диагностика.

Полные инструкции собраны в [оглавлении документации](../README.md). Для уже установленной панели используйте руководство обновлятора, а не повторный запуск установщика.
