# Принятие условий в Telegram (#76)

В «Настройки → Бот → Ссылки» задайте ссылки на пользовательское соглашение, публичную оферту и политику возврата. Бот показывает заполненные HTTP(S)-ссылки и кнопку «Принимаю» перед доступом к меню. Если документов нет, дополнительный шаг не появляется.

Согласие запрашивается и у существующих пользователей, если они ещё не принимали условия через бота. Оно хранится в таблице `telegram_consents`: Telegram ID, дата принятия и ссылки на принятые документы. После перезапуска повторное согласие не требуется. Замена ссылки в настройках требует нового согласия; изменение текста по прежнему адресу автоматически не определяется.

Реферальная ссылка, промокод, подарок, продление и привязка аккаунта сохраняются до принятия условий. Старые кнопки и другие команды не обходят этот шаг. Повторное нажатие «Принимаю» не запускает отложенный переход второй раз.

Обновляйте API и бот вместе. Стандартный запуск API применяет миграцию `20261016220000_telegram_consent`. При ручном запуске сначала выполните `npm --prefix backend run db:migrate` и `npm --prefix backend run db:generate`, затем пересоберите API и бот.
