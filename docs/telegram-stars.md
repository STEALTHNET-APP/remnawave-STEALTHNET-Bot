# Telegram Stars

Поддержка задачи #37. Настройка: **Настройки → Платежи → Telegram Stars**.

Владелец сервиса задаёт цены тарифов в рублях и стоимость одной звезды для своего сервиса. Сумма счёта — цена покупки после скидок, разделённая на эту стоимость и округлённая вверх. Например, 301 ₽ при настройке 2 ₽ за звезду — 151 ⭐. Это настройка магазина, а не официальный курс покупки или вывода Stars.

По умолчанию способ отключён, стоимость звезды равна нулю. Для включения нужны основной `BOT_TOKEN`, положительная стоимость звезды и включённый переключатель. Покупатель должен привязать Telegram к аккаунту. Оплата доступна для рублёвых тарифов, подарков, дополнительных опций, гибкого тарифа, прокси, Sing-box и пополнения рублёвого баланса.

В Mini App счёт открывается через Telegram `openInvoice`, в обычном браузере — по ссылке Telegram. Цена и владелец счёта проверяются сервером. Подтверждение `pre_checkout_query` не выдаёт покупку: начисление происходит только после `successful_payment`. Повторные подтверждения не начисляют покупку повторно. Отменённый после подтверждения счёт нужно создать заново.

Пропущенные подтверждения проверяются по истории транзакций Telegram раз в минуту. Если выдача покупки завершилась ошибкой или сервер остановился во время её выполнения, требуется проверка администратора. Автоматическая повторная выдача в неопределённом состоянии не выполняется.

В карточке платежа администратор может вернуть Stars в Telegram. Пополнение внутреннего баланса и денежные реферальные начисления отменяются. Выданные подписки и бонусные дни при необходимости отключаются отдельно. Для обращения по оплате в боте есть `/paysupport`.

Проверки:

```sh
cd backend
npm run build
node --experimental-vm-modules tests/telegram-stars-invoice.mjs
node --experimental-vm-modules tests/telegram-stars-postgres.mjs
cd ../bot
npm run build
node --experimental-vm-modules tests/telegram-stars.mjs
```

Тест PostgreSQL требует настроенного `DATABASE_URL`, создаёт временные записи и удаляет их. Telegram API и выдача подписок в нём подменены: реальных списаний и сетевых обращений к Telegram нет.

Документация Telegram: https://core.telegram.org/bots/payments-stars
