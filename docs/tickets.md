# Работа с тикетами

Откройте **Тикеты** в меню администратора. Клиентские обращения должны быть включены в настройках панели.

## Ответить нескольким клиентам

1. Отметьте нужные обращения галочками. Проверьте количество выбранных.
2. Нажмите **Ответить**, введите текст и при необходимости добавьте изображения.
3. Если вопрос решён, включите **Закрыть тикеты после ответа**. Без этой галочки обращения останутся открытыми или откроются снова.
4. Отправьте ответ и дождитесь сообщения о результате.

Одно действие поддерживает до 500 обращений, 10000 символов и 5 вложений. Поиск работает по загруженному списку, который содержит до 500 последних обращений.

## Закрыть, открыть или удалить

Для нескольких обращений используйте галочки и соответствующую кнопку массового действия. При повторном массовом закрытии уже закрытого тикета его срок хранения не начинается заново.

**Удалить всё…** предлагает два варианта: только закрытые обращения или все обращения. Этот выбор относится ко всей базе тикетов, а не только к текущему поиску. Удаление окончательное: сообщения исчезнут, а файлы удалятся, когда больше не используются другими тикетами.

## Хранение закрытых обращений

1. Нажмите **Срок хранения**.
2. Укажите число и единицу времени, затем сохраните.
3. Значение **0** отключает автоматическое удаление. По умолчанию оно выключено.

Очистка запускается раз в **5 минут**, до 500 подходящих обращений за один проход. Отсчёт идёт от закрытия тикета. Новое сообщение клиента открывает обращение снова, и оно больше не подходит для удаления как закрытое.

При обновлении до 6.8.2 для старых закрытых обращений за дату закрытия принимается дата их последнего изменения. Если включить короткий срок, такие старые обращения могут попасть под следующую очистку. Сначала сохраните бэкап базы.
