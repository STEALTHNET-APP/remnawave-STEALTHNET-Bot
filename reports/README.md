# STEALTHNET Reports

Отдельный трекер ошибок для `reports.stealthnet.app`. Не меняет базу панели.

## Возможности

- Форма без регистрации: описание, раздел, версия, ожидаемый и фактический результат, контакт и до трёх скриншотов.
- Публичный список, поиск, статусы и отдельные страницы опубликованных заявок.
- Новые заявки по умолчанию закрыты. Администратор проверяет текст перед публикацией.
- Контакты и вложения всегда доступны только администраторам, в том числе после публикации описания.
- Вход через аккаунт администратора панели, включая её 2FA. Аккаунты менеджеров не допускаются. Пароль не сохраняется. Сессия трекера действует 30 минут.
- Изображения перекодируются в JPEG, метаданные не сохраняются. Исходные имена файлов не используются.
- Ограничения запросов, размеров файлов, защита запросов от чужих сайтов, журнал смены статусов.

## Запуск

Нужны Docker Compose и доступ к API панели из сети контейнера. В `compose.yml` задайте `PUBLIC_URL`, `PANEL_URL` и имя существующей Docker-сети `PANEL_NETWORK`. По умолчанию API — `http://api:5000`, сеть — `stealthnet_stealthnet`.

```sh
docker compose -f reports/compose.yml up -d --build --wait
```

Reverse proxy должен передавать запросы на `stealthnet-reports:8080`, устанавливая `Host`, `X-Real-IP` и `X-Forwarded-Proto`. Значение `X-Real-IP` нужно перезаписывать адресом соединения, а не принимать от посетителя. Порт контейнера не публикуется на хосте. HTTPS и сертификат настраиваются отдельно для домена трекера.

Админка: `/admin`. Список заявок: `/`. Новая заявка: `/new`.

## Данные и резервные копии

SQLite и вложения находятся в отдельном томе `reports_reports_data`, каталог `/data`. Имя тома может отличаться при другом Compose project name. Обычное обновление контейнера сохраняет данные.

```sh
docker exec stealthnet-reports python backup.py
```

Скрипт делает согласованный снимок SQLite и сохраняет вложения из этого снимка в `/data/backups`. Удаляет только собственные архивы старше трёх суток после успешного создания новой копии. На сервере рекомендуется ежедневный запуск и отдельное копирование архивов за его пределы. Локальные архивы не защищают от потери сервера.

Для восстановления остановите контейнер, сохраните текущее содержимое тома, распакуйте выбранный архив в том и восстановите владельца файлов UID 10001. Старые `reports.sqlite-wal` и `reports.sqlite-shm` не переносите поверх восстановленного снимка. Затем запустите контейнер и проверьте `/api/health`.

Если свободно меньше 2 ГБ, приём новых заявок приостанавливается. Уже сохранённые заявки остаются доступны.

## Проверки

```sh
python -m venv .venv
.venv/bin/pip install -r reports/requirements.txt
DATA_DIR=/tmp/stealthnet-reports-test .venv/bin/python -m unittest discover -s reports/tests -v
node --check reports/static/app.js
```

Синхронизации с GitHub, почтовых уведомлений и регистрации посетителей нет. Это самостоятельный трекер с ручной модерацией.
